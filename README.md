# RL3DMaker — Demonstração do painel

Este site é uma demonstração de um painel para controle de custos, entradas e estoque de filamentos.

## Sobre os dados

- Os dados que você inserir são armazenados somente no navegador e no dispositivo que você estiver usando.
- As informações não são enviadas para a RL3DMaker, para o responsável pelo site ou para outros visitantes.
- Cada cliente usa seu próprio navegador e não vê os lançamentos feitos por outras pessoas.
- Não há conta, login, banco de dados online ou sincronização entre dispositivos.
- Se outras pessoas usarem este mesmo navegador e dispositivo, elas poderão encontrar os dados de demonstração salvos.
- Os dados podem permanecer salvos no navegador. Use a opção **Apagar dados** ao terminar o teste.
- Não informe dados pessoais, informações de clientes nem valores financeiros reais. Use somente dados fictícios para testar.

## O que você pode testar

- Cadastrar um rolo de filamento: a compra aparece como saída no caixa e o material entra no estoque.
- Registrar uma venda como entrada ou outro custo como saída.
- Registrar o consumo de filamento para atualizar o estoque restante.
- Conferir o saldo do caixa e o peso de material disponível.
- Baixar um arquivo de backup ou apagar os dados de demonstração.
